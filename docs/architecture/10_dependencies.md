# 10 Dependencies

The project leverages several key libraries to provide its core functionality.

| Library | Role |
| :--- | :--- |
| **Media3 (ExoPlayer)** | Core audio playback engine. |
| **JCIFS-NG** | SMBv2/v3 protocol client for network access. |
| **ML Kit Barcode** | Fast and accurate QR code recognition. |
| **CameraX** | Modern Android camera API for the scanning interface. |
| **Jetpack Compose** | Modern toolkit for building the native UI. |
| **DataStore** | Reactive data storage for app settings. |
| **Gson** | JSON parsing for mapping and configuration files. |
| **Coil** | Image loading for album artwork. |
